# NaturalAGI Project File Formats

## Core Development Files

### Python Ecosystem
- **`.py`** - Python source code files containing the main application logic

### Data Science & Machine Learning
- **`.png`** - Image files, likely training data and visualizations
- **`.ipynb`** - Jupyter notebook files for interactive analysis

### Configuration & Documentation
- **`.json`** - JSON configuration and data files
- **`.yaml`** - YAML configuration files
- **`.yml`** - YAML configuration files (alternative extension)
- **`.toml`** - TOML configuration files (Python packaging)
- **`.md`** - Markdown documentation files
- **`.txt`** - Plain text files
- **`.xml`** - XML configuration/data files

## Development Tools & Build Systems

### Build & Compilation
- **`.build`** - Build configuration files
- **`.whl`** - Python wheel distribution packages
- **`.lock`** - Lock files for dependency management

### Scripts & Executables
- **`.sh`** - Shell scripts

## Data & Media Files

### Image Formats
- **`.png`** - Portable Network Graphics (main image format)
- **`.jpg`** - JPEG images
- **`.gif`** - Graphics Interchange Format (animated images)
- **`.svg`** - Scalable Vector Graphics
- **`.bmp`** - Bitmap images

### Data Files
- **`.csv`** - Comma-separated values files
