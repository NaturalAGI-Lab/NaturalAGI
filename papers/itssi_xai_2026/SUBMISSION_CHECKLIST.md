## Лишилося за автором

1. **Формули → MathType.** Windows + Word: MathType → Convert Equations → Whole document.
   ⚠️ **Робити останнім кроком**: `generate_paper.py` перезбирає .docx з нуля і знищує всі OLE-об'єкти.
   Пізніші правки — лише через LibreOffice, який зберігає OLE побайтово.
   Перевірка без Word: `unzip -l itssi_xai_2026.docx | grep -c embeddings` → 20;
   `grep -c 'Equation.DSMT4'` → 20; `grep -c '<m:oMath'` → 0.
2. **Декларація про використання ШІ** — заглушка в `DECLARATIONS["ai"]`; редакція вимагає п'ять
   пунктів, перелічені в коментарі перед полем у `content.py`.
3. **УДК** — зараз `004.93`. В опублікованій статті теж `004.93`; підтвердити в бібліотеці.
4. **Телефон** у блоці відомостей про автора — заглушка `+38(0XX)XXX-XX-XX`.
5. **Бібліографічні описи / Bibliographic descriptions** — блок у хвості опублікованої статті
   містить номер випуску, сторінки та DOI, яких до прийняття не існує. Проставляє редакція.

## Збірка

```bash
cd papers/itssi_xai_2026
make all                                   # docx → pdf → кількість сторінок
../../.venv/bin/python render_figures.py   # перерендер рисунків з артефактів
../../.venv/bin/python renumber_refs.py    # переобчислити номери після правки цитат
```

`content.py` — єдине джерело правди для бібліографії (`REFERENCES`). Окремого
`references.bib` немає: він розходився зі списком у `content.py` і його вилучено.
`renumber_refs.py` переписує і `REFERENCES`, і `CITATION_MARKERS` у
`generate_paper.py`, аварійно завершуючись на нецитованому джерелі або на
неоднозначному збігу; збірка додатково падає на будь-якому непере­твореному
цитуванні виду "(Автор, рік)".
