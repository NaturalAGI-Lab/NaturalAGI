# Skeletonization

This component is responsible for skeletonizing images using the Growing Neural Gas (GNG) algorithm.
The result is a skeletonized image that can be used for further processing or analysis.
The format of the output is a NetworkX graph (JSON) that represents the skeleton.

## Response

The response is a JSON string that represents the skeleton.

## Settings

The settings are defined in the `settings.py` file.
